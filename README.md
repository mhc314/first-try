# 摄影解谜游戏

一款正在构思中的像素风摄影解谜游戏。玩家扮演摄影师，接受拍摄委托，通过观察场景、调整相机参数并提交照片获得报酬。

游戏希望让玩家通过拍摄和比较照片，理解光圈、快门速度、ISO 与对焦对成像的影响。早期委托以自然物品为主，后续计划加入原创的超自然拍摄对象；相机和器材升级是未来可能加入的功能。

## 首个可玩版本

- 摄影棚教程：体验对焦、景深、运动模糊、亮度和噪点。
- 拍照及照片结果预览。
- 根据照片是否满足要求，给出可理解的反馈。
- 一项综合拍摄挑战；随后尝试加入一份自然场景委托。

## 试玩摄影棚原型

这是使用 Godot 4.6.1 制作的本地原型。Windows 下双击 `start_game.bat` 即可启动。启动脚本会寻找项目文件夹内的 `tools/godot/Godot_v4.6.1-stable_win64.exe`；本地引擎放在 `tools/` 中，不纳入 Git 版本管理。

1. 左侧是取景器。使用底部菜单调整光圈、快门速度、ISO 和对焦位置。
2. 点击“拍照并检查任务”，右侧会保留照片、相机参数和具体反馈。
3. 完成当前挑战后，点击“下一项”。可以返回上一项，参数可随时重置。
4. 第四项会自动调暗摄影棚灯光；其他练习使用正常灯光。

照片的亮度、景深、运动模糊和噪点采用便于观察的简化模拟，不是精确的光学成像。原型采用固定构图，目标都在画面内；自由取景、移动、报酬和升级仍待开发。游戏进度和照片仅在本次运行期间保留。

## 开发环境

项目推荐使用 Godot 4.6.1 标准版。将 Windows 官方版本解压到 `tools/godot/`，并在该目录放置空文件 `_sc_`，可启用 Godot 的便携模式。`.godot/` 是引擎自动生成的项目缓存，不提交到 Git。
