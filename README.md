# 摄影解谜游戏

一款正在构思中的像素风摄影解谜游戏。玩家扮演摄影师，接受拍摄委托，通过观察场景、调整相机参数并提交照片获得报酬。

游戏希望让玩家通过拍摄和比较照片，理解光圈、快门速度、ISO 与对焦对成像的影响。早期委托以自然物品为主，后续计划加入原创的超自然拍摄对象；相机和器材升级是未来可能加入的功能。

## 首个可玩版本

- 摄影棚教程：体验对焦、景深、运动模糊、亮度和噪点。
- 拍照及照片结果预览。
- 根据照片是否满足要求，给出可理解的反馈。
- 一项综合拍摄挑战；随后尝试加入一份自然场景委托。

## 试玩摄影棚原型

这是使用 Godot 4.6.1 制作的本地原型。Windows 下双击 `start_game.bat` 即可启动。启动脚本会寻找项目文件夹内的 `tools/godot/Godot_v4.6.1-stable_win64.exe`；本地引擎放在 `tools/` 中，不纳入 Git 版本管理。

1. 左侧是取景器。使用底部菜单调整光圈、快门速度、ISO 和对焦位置。
2. 点击“拍照并检查任务”，右侧会保留照片、相机参数和具体反馈。
3. 完成当前挑战后，点击“下一项”。可以返回上一项，参数可随时重置。
4. 第四项会自动调暗摄影棚灯光；其他练习使用正常灯光。

照片的亮度、景深、运动模糊和噪点采用便于观察的简化模拟，不是精确的光学成像。原型采用固定构图，目标都在画面内；自由取景、移动、报酬和升级仍待开发。游戏进度和照片仅在本次运行期间保留。

## 未来设计方向

以下内容是目前的设想，尚未在试玩原型中实现，具体方案会随着测试和迭代调整。

### 探索与自由取景

- 玩家扮演摄影师，通过观察和探索场景，自行决定拍摄对象与构图；取景器只显示相机当前对准的区域，而不是直接展示整个场景。
- 玩家通过鼠标控制相机的取景方向，不再从菜单中选择一个预设的对准物体。进入取景模式后，可以调整主体在画面中的位置，以及选择拍入哪些物品。
- 场景切换参考《绣湖》系列的点击式探索：在画面边缘显示可用的方向箭头，点击后查看其他方向，或移动到相邻的预设位置。箭头具体代表转身还是移动，由场景和界面设计明确区分。
- 游戏继续采用像素风；后续拍摄内容可从自然物品逐渐扩展到原创的超自然对象。

### 镜头、委托与拍摄判定

- 后续考虑加入更换镜头和不同焦距。在相同画幅与拍摄位置下，不同焦距可以提供不同的视角范围，影响玩家如何构图。
- 玩家接受拍摄委托并通过完成任务获得报酬；报酬可用于未来可能加入的相机或器材升级。
- 拍摄判定计划结合委托目标和实际画面，例如检查目标是否进入画面、是否被遮挡、占画面的大小，以及曝光等参数是否满足任务要求。具体规则尚待设计与测试。

### 场景实现方案

目前考虑两条路线，尚未最终确定：

1. **2D 像素场景**：使用较大的场景图，让玩家控制取景区域。早期制作相对简单，但表现不同视角下的空间和遮挡变化需要额外设计。
2. **固定位置的简单 3D 场景**：用箭头在预设位置间切换，玩家在当前位置用鼠标转动相机。这个方向更便于尝试空间、遮挡和不同镜头视角，但初期制作与测试工作量预计更高。像素风可以通过低分辨率画面和简洁造型探索。

目前倾向先制作一个简单 3D 小样：一个房间、两个可切换位置、鼠标自由取景、一个拍摄目标和两种镜头视角。先测试操作和画面效果，再决定后续采用哪种方案。之前讨论的粗略估计是：在相同小样范围下，简单 3D 的工作量可能约为 2D 的 1.5～2.5 倍；实际比例需要通过试作验证。

## 开发环境

项目推荐使用 Godot 4.6.1 标准版。将 Windows 官方版本解压到 `tools/godot/`，并在该目录放置空文件 `_sc_`，可启用 Godot 的便携模式。`.godot/` 是引擎自动生成的项目缓存，不提交到 Git。
